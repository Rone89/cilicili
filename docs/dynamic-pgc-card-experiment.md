# 动态番剧卡片与播放增强实验

入口：我的 → 开发者与诊断 → 实验开关 → 动态番剧卡片与播放增强实验。默认关闭，设置持久化；关闭后恢复原有动态图文回退展示，不清理账号或观看记录。

## 行为与范围

- 仅识别 `DYNAMIC_TYPE_PGC` / `DYNAMIC_TYPE_PGC_UNION` 的 `major.pgc`；同样支持 `orig` 内的番剧动态。普通文字提及追番不会转换。
- 独立原生番剧卡片：16:9 封面、标题，以及接口实际返回的 badge、duration_text、stat.play、stat.danmaku；转发使用紧凑卡片。正文、作者、原动态评论 OID/type 和动态互动不变。
- 移除回退图文中的重复番剧封面与标题，保留正文及其他图片。封面复用 CDN 缩略图、RemoteImageCache 和现有视频封面阴影设置。
- 优先 `epid`，仅在缺失时解析 Bilibili 正规 `/bangumi/play/ep...` 链接；`season_id` / `ss...` 为无分集信息时的降级。不会将 `id`、`aid` 或真假布尔值当作分集 ID。
- 复用 `fetchPgcSeasonInfo(seasonID:epID:)`、`/pgc/view/web/season` 和现有 PGC 播放链路，不新增网络端点或卡片级分集预请求。
- 指定分集必须在返回的可播放分集中准确匹配，优先于云端续播记录；失效或缺少可播放 CID 时提示失败，绝不自动播放另一集。原有仅 season 的搜索/追番入口仍按原续播规则选择。
- 分集加载失败支持重试、网页查看和返回。重试使用随视图取消的 `.task`，避免退出后的状态提交。
- 番剧继续显示于“全部”，不加入“视频”筛选；最常访问区和多账号配置不变。

## 真机验收清单（待验证）

1. 实验关闭：PGC 动态和转发恢复原有图文展示；普通投稿、图文及追番文字不变。
2. 实验开启：PGC 正常/转发卡片、封面、徽标、时长和真实统计正确，无重复图片/标题；空值显示占位。
3. “全部/视频”切换：番剧仅在全部，最常访问区不变；刷新、翻页不增加卡片级分集请求。
4. 点击具体一集，确认播放器 episodeID/CID 与动态对应，云端进度在另一集时也不误播；季级入口仍续播。
5. 网络超时、地区/会员限制、分集失效：显示真实失败，重试/网页查看/返回可用，无假成功。
6. 快速点击、加载中退出、从转发/评论弹窗的个人空间打开，确认导航与取消正常。
7. 未登录/普通登录/切换动态账号与播放账号，确认沿用现有认证机制，没有跨账号新缓存或状态。
8. 深色/浅色、动态字体、VoiceOver、封面阴影开关及实验立即开关后的列表展示。
