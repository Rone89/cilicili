## 去重与说明边界

- 已转正功能按当前默认行为描述，不继续列为实验；已删除的首页切换样式设置、视频固定底栏实验及自定义底部模糊回退不作为新增内容。
- 大图 2400px 和 1920px 是中间版本，最终静态预览基准为 1600px；长图使用独立解码预算，GIF／Live Photo 沿用原有媒体处理，并非所有媒体的最长边均固定限制为 1600px。
- 原图加载有内存保护，不能保证超大图片完全按原始像素解码。
- 评论修复不代表与官方客户端所有内容完全一致；对话仍单次最多 20 条，未新增对话游标分页。
- 视频架构与番剧启动流程的代码优化有实际实现依据，但缺少同条件真机性能数据，不宣称具体帧率或加载耗时改善比例。
- 收藏批量操作、公开空间等依赖服务端权限；不把测试代码的存在等同于真实账号操作验收通过。
- 构建缓存、诊断、测试 fixture、内部重构及致谢不计入面向用户的主要功能条目。
- 当前工作区已有的 SkeletonBlocks、VideoDetailCommentsSectionHeader、VideoDetailInitialCommentsSection 改动及 `docs/local-main-update-analysis-2026-10-06.md` 不计入已提交版本差异，也不纳入本轮提交。
