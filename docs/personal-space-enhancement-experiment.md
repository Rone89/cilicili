# 个人空间增强实验：第一轮

入口：我的 → 开发者与诊断 → 实验开关 → 个人空间增强实验，默认关闭。

## 本轮范围

开启后保留 UploaderView 及现有导航，新增资料背景、等级、有效会员标签、认证、地区与「主页」内容概览。
空间背景图固定在滚动区域外，覆盖顶部安全区与导航栏；下拉刷新不移动或拉伸背景图，资料和内容正常滚动。没有背景图时保留普通导航栏。
顶部滚动边缘使用系统 `.soft` 效果。主页、动态、投稿、合集切换器位于导航栏中央，右侧为非主题色的系统分享按钮。
粉丝、关注、获赞、投稿数采用等宽居中的四列布局，统计栏和下方原生分隔线的左右边距均为 20pt。
概览来自单次 APP `/x/v2/space`，采用现有 Android APP 签名与主账号请求上下文。
投稿、点赞、投币、收藏、追番只展示服务器返回的有效预览；数量缺失时不推断为零。
点赞/投币视频不把空间用户当作视频作者；追番复用现有 PgcSeasonRoute。
收藏预览使用 PiliPlus 分享功能相同的真实收藏夹网页链接，本轮不扩展原生收藏完整分页。

主页首屏不额外请求完整投稿列表。点击投稿、动态、合集后复用现有加载与分页组件。
切换标签不重复请求已加载的空列表。手动刷新仍可重试。
APP 聚合失败时只请求公开 `/x/web-interface/card` 保留基本资料，概览仍展示失败及重试入口。

实验关闭后继续使用原有三标签页面、资料与投稿加载路径，不删除任何用户数据。

## 账号和隐私

每个增强 ViewModel 捕获主账号身份、凭据版本、账号用途启用状态与游客模式。
切换账号/更新凭据/改变游客模式时重建增强页面并清理旧内容；旧响应不能提交到当前界面。
游客模式不发送账号 cookie 或 access_key。不持久化空间聚合响应。
隐私设置缺失表示未知；仅查看自己的空间时展示接口明确返回的「仅自己可见」标识。
关注仍调用已有 relation API，增加可选 expectedAccountMID 防止请求前账号变化，不允许关注自己。
所有服务器写操作仍沿用现有认证；本轮不增加资料编辑或隐私写操作。
